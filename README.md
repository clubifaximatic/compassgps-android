# compassgps-android
Just a simple Compass App for android

The application shows a compass ring with three values inside:
1. heading (degrees)
2. altitude
3. speed (km/h)

The menu can be used for changing the unit system: metrics or imperial

Playstore: https://play.google.com/store/apps/details?id=com.elllimoner.compassgps
